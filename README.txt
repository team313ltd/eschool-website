SCHOOLSUITE INTERACTIVE DEMO — FIXED PACKAGE

HOW TO OPEN
1. Right-click the ZIP file, choose "Extract All..." on Windows.
2. Open the extracted "eschool_showcase" folder.
3. Double-click "index.html" to see the homepage.
4. Select Teacher, Student, Parent, or School Admin to explore their guided demos.

IMPORTANT
- This update fixes a browser JavaScript naming conflict that caused a blank white page.
- Every HTML file includes its styles and scripts. No server, internet, app download, or database is needed.
- All pages include prerendered content, so even if JavaScript is disabled the pages display content (interactive changes need JavaScript).
- Sample role interfaces and records are visual mockups, not the actual eSchool app and not a functioning backend.
- Temporary brand name SchoolSuite. Replace with your school software brand when ready.
