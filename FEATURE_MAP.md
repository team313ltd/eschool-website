# Public showcase feature boundaries

Principal/Admin: school configuration, classes, students, guardians, teachers, timetables, attendance, offline examinations, grades, manual fees, notices, leaves, individual reports, admissions, school calendar, appropriate roles/permissions.
Teacher App / Web Portal: class assignments, attendance, lessons/topics, classroom homework, results/marks, timetables, announcements, leave, communication.
Student App: subjects, timetables, homework instructions, attendance, offline exam schedules, results, manual fee records, notices, messages, calendar.
Parent App: linked children, attendance, homework visibility, results, manually recorded fees, communication, leave/calendar.

Excluded from public site and from this package's advertised features: school website, online fee collection, online examinations, staff creation, online homework-file submissions, bulk reporting.
