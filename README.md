# SkolSup — Website

Standalone HTML/CSS/JavaScript advertising website with five interactive product demos, monthly pricing calculator and three policy pages.

## Open locally

Double-click `index.html`. No server required to view this static showcase.

## Launch checklist

1. Verify that the WhatsApp number and social profile URLs are correct before publishing.
2. Review Terms, Privacy and Data Security pages against actual hosting, backup, access-control and retention arrangements.
3. Keep demo records fictional; never publish real pupils' or parents' data.
4. Confirm deployment scope, payment conditions, refund settlement and monthly billing rules in each school agreement.
